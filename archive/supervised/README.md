# Archived supervised work

This directory preserves the supervised TRACE-ESUS comparison as it existed
before removal from the executable package on 2026-08-13. It is provenance, not
an importable package surface or active preliminary evidence.

The scientific reason for archival is structural: real ESUS cohorts cannot
provide mechanism labels for model training. The active package therefore
contains only `endotype_discovery`, `transportability`, and `counterfactual`.

Locked cited outputs were deliberately not moved here. They remain at
`outputs_locked/outputs_associative_vs_scm/` so the original provenance tree is
unchanged.
